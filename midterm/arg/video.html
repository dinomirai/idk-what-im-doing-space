Lesson 7: Adding a video

Goal: Embed a local MP4 with a play button, volume controls and a working file path.

A video can live in the same folder as your other media. You do not need a video plugin or an embedded YouTube player for a local MP4.

The example file

This project includes Apple Macintosh 1984 Commercial.mp4 in the images folder. It is about 30 seconds long and shows Macintosh software demonstrations. The supplied filename gives its title; it is not the hammer-throwing “1984” commercial.

The HTML

<video controls preload="metadata" width="480"
       aria-label="Macintosh demonstration commercial">
    <source src="images/Apple%20Macintosh%201984%20Commercial.mp4"
            type="video/mp4">
    Your browser cannot play this video.
</video>
<p><a href="images/Apple%20Macintosh%201984%20Commercial.mp4">
    Open the MP4 file
</a></p>
  • controls gives the visitor play, pause, volume and other browser controls.
  • preload="metadata" asks for basic information such as duration before playback. The browser decides how much to load.
  • <source> gives the path and file type. It has no closing tag.
  • %20 represents a space in a URL. The actual filename still contains spaces.

Try the included video

Open the MP4 file | Read the visual description

The supplied clip has no captions. The linked description covers the pictures, not a verified speech transcript. The HTML lesson is fully written out here, so you do not need the clip's sound to do the exercise.

Keep the player inside the page

video {
    max-width: 100%;
    height: auto;
}

The player can shrink to fit a narrow screen. Do not add autoplay; let people choose when it starts.

What about captions?

Captions show speech and meaningful sounds. A transcript is a separate written record. Neither is created automatically by adding controls. To add checked captions later, put a WebVTT file beside the video and place a <track> inside <video>.

<!-- Only add this after creating and checking the caption file. -->
<track kind="captions" src="images/commercial-captions.vtt"
       srclang="en" label="English" default>

That line is an example, not an active caption track in this project. There is no caption file included. Prerecorded video with meaningful audio needs accurate captions to satisfy WCAG 1.2.2; a short visual description is not a substitute.

Try it

Press play, pause the clip and change the volume. Then open the direct MP4 link.

Check: The player works without autoplay and the direct link points to the same local file.

If it goes wrong

If the video is missing, check the folder, spaces, capital letters and .mp4 extension. Text between the video tags is only a fallback for browsers that do not support the element, so keep a separate file link too.
