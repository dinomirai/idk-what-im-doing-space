Lesson 6: Boxes and layout

Goal: Use margin, padding, a float, clear and a clearfix to arrange a small page.

Every element takes up a box. Its content is inside, then padding, then a border. Margin leaves room outside that border.

.demo-box {
    padding: 12px;
    border: 2px solid navy;
    margin: 12px;
}

Padding is between these words and the border. Margin is outside the border.

Centre a container

.page {
    max-width: 900px;
    margin: 0 auto;
}

max-width puts a limit on the width. The two auto side margins share the extra space. That centres the container when the window is wider than it.

A small float example

A float can put a picture on the left while text wraps beside it. The example uses the house image from lesson 5.

<div class="float-example">
    <img class="float-house" src="images/little-house.png"
         alt="A small blue house with a yellow door">
    <p>This text wraps beside the picture.</p>
</div>
<p class="after-float">This starts below the picture.</p>
.float-house {
    float: left;
    width: 96px;
    margin-right: 12px;
}
.after-float {
    clear: both;
}

This text wraps beside the picture.

This starts below the picture.

Keep a float inside its parent: clearfix

A floated child can stick out of a short parent. A clearfix adds an empty piece after the children and clears the float. This keeps the parent's border around the picture too.

.float-example::after {
    content: "";
    display: block;
    clear: both;
}

::after means “add something after this element's content.” The empty quotes mean no visible words are added. The footer on this site also uses clear: both to sit below the sidebar.

Try it

Copy the float example. Make its paragraph one short sentence, then remove and restore the clearfix rule.

Check: With the clearfix, the parent remains tall enough for the picture. The paragraph with clear starts below it.

If it goes wrong

Floats do not need to control every part of a page. One small example is enough to see the difference between wrapping text, clearing it and containing it.
