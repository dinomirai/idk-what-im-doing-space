FAQ

Mac here. I decided to answer some possible common FAQ questions.

Who is the intended learner?

The intended learner is someone who is new to HTML and CSS, or someone who has seen them before but forgets the tags. They should know how to save a file and open it in a browser. I don't think I fit right as an educator. Really, I made this for my sister. I don't expect others to find this.

Why this instructional format?

The site uses short text explanations, code examples and visible results. A learner can read one section and try it in their own file. The examples stay on the page so they do not have to remember everything. Text also works locally without loading a video or signing in.

How does the navigation guide learning?

The same menu is on every page. The lessons are numbered, and previous and next links show an order. The glossary helps someone find a forgotten tag without rereading every lesson. Jump links move to sections on longer pages. I think that's pretty simple and easy to navigate? Kay is only 8, so I had to make sure navigation is as straightforward as possible.
