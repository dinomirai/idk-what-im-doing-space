Welcome, internet visitor!

This is a beginner's guide to making a tiny website. You do not have to remember every tag. The glossary is here for that.

Before you start

You need a plain text editor and a browser. You should know how to make a folder and save a file. That is enough to start.

Make a practice folder. Save your first page as index.html and the stylesheet as style.css. Open the HTML file in your browser.
