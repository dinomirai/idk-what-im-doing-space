When you know what you want but forget the name, start here.

Word list | Quick copy

Word list

Element
A whole piece of HTML, such as <p>Hello</p>. Lesson.
Attribute
Extra information in an opening tag, such as href="about.html". Lesson.
Heading
A title or section name. The main title is <h1>; use levels in order. Lesson.
Paragraph
A text block written with <p> and </p>. Lesson.
List
<ul> uses bullets, <ol> uses numbers, and each item is <li>. Lesson.
Selector
The part before a CSS rule's braces. It chooses what to style. Lesson.
Class
A reusable name: class="box" in HTML, .box in CSS. Lesson.
ID
A unique name on one page, such as id="top". Link to it with href="#top". Lesson.
Fallback font
The next font the browser can try if the first one is unavailable. Lesson.
RGBA
Red, green, blue and alpha (opacity). Lesson.
Relative path
A file address starting from the current file, such as images/photo.png. Lesson.
Alt text
A short text alternative for a useful image. A decoration can have alt="". Lesson.
Padding
Space inside the border. Lesson.
Margin
Space outside the border. Lesson.
Float
Places an element to one side and lets text wrap beside it. Lesson.
Clear
Moves an element below earlier floats. Lesson.
Clearfix
A small CSS rule that helps a parent contain its floated children. Lesson.
Video controls
The browser's play, pause and volume controls, enabled with controls. Lesson.
Captions
Timed text for speech and meaningful sounds. Not the same as a short visual description. Lesson.
WCAG
Web Content Accessibility Guidelines, published by W3C. Lesson.
Focus
The link or control that keyboard input will act on. Keep its outline visible. Lesson.
Details and summary
An HTML disclosure control for opening and closing extra content. Lesson.

Quick copy: link the stylesheet

Put this inside <head> when the two files are beside each other.

<link rel="stylesheet" href="style.css">
