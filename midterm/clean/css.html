Lesson 3: Basic CSS

Goal: Connect a stylesheet and change colour, padding and margin.

HTML says what something is. CSS changes its appearance. A CSS rule has a selector, then a property and value inside curly brackets.

1. Connect the file

Save a plain text file called style.css beside your index.html. Put this line inside the HTML page's <head>:

<link rel="stylesheet" href="style.css">

2. Write a few rules

Put these rules in style.css. The h1 selector chooses every main heading on the page.

body {
    background-color: #fffde9;
    color: #000000;
    font-family: "Times New Roman", serif;
    font-size: 18px;
}
h1 {
    color: #000080;
}

3. Reuse a class

A class is a name you can give to several elements. CSS puts a dot before a class name. The HTML name has no dot.

<p class="demo-box">This paragraph has a border.</p>
.demo-box {
    border: 2px solid #000080;
    padding: 12px;
    margin: 12px;
}

Result

This paragraph has a border.

Padding is space inside the border. Margin is space outside the border. The content, padding, border and margin make up the box model.

Try it

Change the padding to 24px. Save and refresh. The space between the words and the border should grow.

Common mistake

If no styles appear, check the filename. style.css and styles.css are different names. Also check that you saved both files in the same folder.
