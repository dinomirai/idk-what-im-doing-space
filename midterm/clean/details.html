Lesson 9: Click-open answers

On this page: The code · Try the real example · Try it yourself · Check your understanding

Goal: Use <details> and <summary> to hide and reveal an answer. This is the independently researched technique for this project.

This little HTML feature is useful for hints and short answers. The browser handles opening and closing it. It does not need a script, plugin or special CSS.

The code

<details>
    <summary>What does HTML stand for?</summary>
    <p>HyperText Markup Language.</p>
</details>

Try the real example

What does HTML stand for?

HyperText Markup Language.

How it works

  1. <details> wraps the whole question and answer.
  2. <summary> comes first and gives the clickable label.
  3. The paragraph after it is the answer. It starts closed.
  4. Click the label to open it. Click again to close it.

You can also press Tab until the summary has focus, then press Enter or Space. Keep the question specific so people know what will open.

To start an answer expanded, add the Boolean attribute open to <details>. Leaving it out starts the answer closed. Keep essential instructions outside the hidden answer.

Try it yourself

Copy the example into your practice page. Change the question to “What does CSS stand for?” and the answer to “Cascading Style Sheets.” Test opening and closing it with a mouse and keyboard.

Use it in small amounts

A hidden answer is handy for a practice question. Keep the main lesson visible so people do not have to open lots of boxes just to read it.

Next, put the pieces together in a small practice site.

Research source: MDN: the details disclosure element. This technique goes beyond the supplied classroom checklist. The research takeaway is that HTML already includes a keyboard-operable disclosure control, which is useful for optional hints and practice answers.

Check: Compare your saved page with the example above, then test the change described in the practice activity.

Check your understanding

Does details need JavaScript? How do you open it with a keyboard?

Show the answer
