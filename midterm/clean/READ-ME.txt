BABY'S FIRST WEB CLASS — WEB DESIGN 412
Zahra R. | Final grading website

HOW TO VIEW
1. Extract the whole ZIP. Do not open the page from inside the ZIP viewer.
2. Open index.html in a current browser.
3. Keep style.css and the images folder beside the HTML files.

No installation, server, extension, framework or internet connection is needed
for the website itself. External reference links require internet access.
The website contains no JavaScript, Python, inline CSS or extra stylesheets.
The repository's unrelated Node sample is not part of this submission.

WHAT TO SUBMIT
Submit this complete folder as one ZIP. It includes 15 HTML pages, one shared
style.css, two local PNG images, this readme, reflection.txt and the teacher
checklist. The same reflection is also available on reflection.html.

LEARNING PATH
Home -> Basic HTML -> Headings and lists -> Basic CSS -> Colours and fonts ->
Links and images -> Boxes and layout -> Small screens -> Accessibility ->
Click-open answers -> Put it together.

The glossary, resources, FAQ and reflection are reachable from every page.
Lessons include objectives, explanations, code, demonstrations and practice.
Optional answers use details and summary, built-in HTML elements.

BEFORE SUBMITTING
Read the reflection and adjust it to accurately describe your own decisions and
experience. It includes an AI-assistance disclosure. Be ready to explain your
HTML and CSS and the researched details/summary technique. Check with your class
notes that details/summary qualifies as outside-class research.
