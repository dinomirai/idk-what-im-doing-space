Lesson 2: Headings and lists

On this page: Headings have levels · Bullets or numbers? · Try it · Check your understanding

Goal: Choose a heading, a paragraph and the right kind of list.

A page is easier to read when its parts have names. Use a heading for a title, a paragraph for a sentence, and a list for a group of items.

Headings have levels

Use one <h1> for the main page title. Use <h2> for sections below it and <h3> for smaller sections. Pick the level for its meaning, not its size.

<h1>My recipe page</h1>
<h2>Toast</h2>
<p>A small breakfast.</p>
<h3>Ingredients</h3>

Bullets or numbers?

<ul> makes a bulleted list. Use it when order does not matter. <ol> makes a numbered list. Use it for steps. Each item needs <li>.

<ul>
    <li>Bread</li>
    <li>Butter</li>
</ul>

<ol>
    <li>Toast the bread.</li>
    <li>Add butter.</li>
</ol>

Result

Ingredients

  • Bread
  • Butter

Steps

  1. Toast the bread.
  2. Add butter.

Give the page a structure

These elements describe whole areas. They do not add a special design by themselves.

<header>
    <h1>My recipe page</h1>
</header>
<nav>
    <a href="index.html">Home</a>
</nav>
<main>
    <h2>Toast</h2>
    <p>A small breakfast.</p>
</main>
<footer>
    <p>Made for class.</p>
</footer>

Try it

Add an ingredients list and a numbered list of steps to your practice page.

Check: The ingredients have bullets and the steps have numbers. The heading describes what follows it.

Comments explain your source

A comment is a note for someone reading your HTML. The browser does not display it as page text.

<!-- Main learning content starts here. -->

Use short comments to label sections. CSS comments use a different form: /* Shared heading styles */.

If it goes wrong

Do not use a heading just to make text bigger. A normal sentence belongs in a paragraph. CSS can change its size later.

Next, connect a CSS file to change the appearance.

Check your understanding

Which list should you use for steps that must happen in order?

Show the answer

Use <ol> with one <li> for each step. Use <ul> when the order does not matter.
