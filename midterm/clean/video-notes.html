Video: visual description

This is a visual description of the supplied 30-second Macintosh commercial. It is not a verified transcript of its soundtrack.

What the pictures show

  1. A beige Macintosh computer is shown with windows on its screen.
  2. The screen demonstrates desktop software, including charts and a document window.
  3. The word “elastic” appears inside a selected box and changes shape.
  4. A picture is moved or edited in a window.
  5. A drawing of a person in a top hat is shown.
  6. The clip ends with the word “Macintosh” on a dark background.

The clip is used as an example of a local video file. The lesson teaches the embedding code, not information spoken in the commercial.
