Project reflection — Zahra R.

On this page: Who is the intended learner? · Why this instructional format? · What design choices make the site easier to understand? · Process and assistance

Who is the intended learner?

This tutorial is for a beginner who has not written HTML or CSS before, or someone who needs short reminders. It assumes only that the learner can make a folder, save a plain text file and open it in a browser. The first lesson starts with a complete small HTML page instead of assuming familiarity with tags.

Why this instructional format?

The site uses short text explanations, selectable code, small image demonstrations and visible results. A learner can work at their own pace, compare code with its output and change one thing at a time. Every lesson includes practice and a question with a revealable answer. The core teaching stays visible; optional answers provide feedback without revealing the answer before the learner tries.

How does navigation guide the learning process?

The same directory appears on every page. Ten numbered lessons move from HTML structure to CSS, links, layout, small screens, accessibility and a final practice site. A current-page label shows where the learner is, and named previous and next links provide a step-by-step route. Page jump links, a glossary, an FAQ and a skip link make it easier to find a section or return to the lesson content.

What design choices make the site easier to understand?

The retro browser frame gives the site a consistent identity, while the lesson area uses dark text, pale backgrounds and familiar fonts. The same heading sizes, spacing, borders and reusable box classes appear throughout. Code examples are separated from results, and objectives and practice checks use repeated patterns. The directory stacks above the lesson on narrow screens. Underlined links, useful image alternatives and visible keyboard focus support different ways of using the site.

Process and assistance

The original concept was a nostalgic browser-style learning site. AI assistance helped revise instructional text, repair HTML and CSS, check local links and organise the submission materials. This version contains only HTML, one shared CSS file and local PNG images, plus plain text documentation. The independently researched technique is the native details and summary disclosure control, explained and sourced in lesson 9.
