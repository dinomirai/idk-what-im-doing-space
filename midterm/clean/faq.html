FAQ

Do I need to memorise every tag?

No. Try one example, then use the glossary when you forget a name. Looking it up is part of working with HTML.

Do I need to install anything?

You need a plain text editor and a browser. Extract the whole ZIP first and open index.html. No package manager, server, plugin or account is needed.

Why does my change not show up?

Save the file, then refresh the browser. Check that you edited the file you opened. If CSS is missing, compare the stylesheet filename with the link in the HTML.

Why do the browser buttons not work?

The old browser frame is decoration. Use the real links inside it to move around the website.

Is this meant to run in Internet Explorer 6?

No. It looks old but uses normal present-day HTML. The details control and video player need a current browser.
