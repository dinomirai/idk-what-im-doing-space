FAQ / something went wrong

On this page: My page opens as text, or its name ends in .html.txt · My CSS does not appear · Does this website save my work? · Can I open everything without a server?

Start with the problem that looks like yours. These answers use the same techniques as the lessons.

My page opens as text, or its name ends in .html.txt

Save it as plain text with the exact name index.html. Show file extensions in your file manager. In the save dialog, choose “All files” if necessary. Open the file in a browser.

My CSS does not appear

Check that the file is called style.css, that it is beside the HTML file, and that this line is inside <head>:

<link rel="stylesheet" href="style.css">

Save both files and refresh the browser. Check the spelling, closing braces and semicolons. See lesson 3.

My link or image is broken

Use the exact folder and filename, including capital letters. An image path such as images/little-house.png starts from the HTML file's location. Do not use a path to your own desktop. See lesson 5.

My jump link does not move anywhere

The hash in href="#example" must match an existing id="example". Put each ID on only one element per page.

My layout has a gap on a phone

Check that your narrow-screen rule resets the lesson's left margin as well as removing the sidebar's float. Add the viewport meta tag. See lesson 7.

The code box is wider than my phone

Long code lines can scroll inside their own boxes. Focus the box with Tab and use the arrow keys to read across, or swipe inside it. The rest of the page should fit the screen.

Does this website save my work?

No. Make and save your practice files in your own text editor. The example input does not send data, and the question boxes do not record progress.

Can I open everything without a server?

Yes. Extract the entire ZIP, then open index.html. Keep the images folder beside the HTML files and style.css. The external resources need an internet connection.
