Resources and credits

On this page: HTML and CSS references · Independently researched technique · Accessibility references · Project and image credits

The lessons explain the core ideas on their own. These optional references provide more detail and need an internet connection.

HTML and CSS references

  • MDN: basic HTML syntax — elements, tags and attributes; lesson 1.
  • MDN: heading elements — meaningful heading levels; lesson 2.
  • MDN: getting started with CSS — rules and external stylesheets; lesson 3.
  • MDN: the box model — content, padding, borders and margin; lesson 6.
  • MDN: float and clear — wrapping and clearing; lesson 6.
  • MDN: Flexbox — a simple row layout; lesson 6.
  • MDN: using media queries — conditional CSS for smaller windows; lesson 7.

Independently researched technique

MDN: the details disclosure element explains <details>, its required <summary> label and the open attribute. Lesson 9 teaches the technique with code, a working example and keyboard instructions. It is also used for optional practice answers throughout this tutorial.

Accessibility references

  • W3C WAI: images tutorial — useful and decorative image alternatives.
  • WCAG 2.2 Quick Reference — accessibility criteria, including contrast and keyboard use.
  • W3C WAI: Easy Checks — starting points for checking a page.

Project and image credits

  • Student project: Zahra R., Web Design 412. The retro browser frame and lesson topics are based on the submitted website.
  • images/little-house.png is the small drawing supplied with the project. It is reused for the image and layout demonstrations.
  • images/internetexplorer6icon.png is the supplied decorative browser icon. The Internet Explorer name and mark belong to Microsoft. The frame is a student design homage.
  • The interface uses system fonts such as Tahoma and Arial; lesson text uses Georgia with a serif fallback. No font download is required.
  • AI assistance was used to revise explanations, repair code and links, improve the layout and prepare project documentation. See the reflection.

The project folder includes reflection.txt and teacher-checklist.txt for the written submission and requirement evidence.
