Lesson 4: Colours and fonts

On this page: Change text and background · Pick a readable font · Try it · Check your understanding

Goal: Choose a readable colour pair and a font with a fallback.

You only need a few colours. This site uses a blue desktop, a grey frame and pale lesson pages. Plain dark text is easier to read than a busy pattern behind every paragraph.

Change text and background

body {
    background-color: #fffde9;
    color: #000000;
}
h1 {
    color: #000080;
}

The six characters after # describe a colour. #000000 is black and #ffffff is white. You can also start with names such as navy.

Pick a readable font

body {
    font-family: "Times New Roman", serif;
    font-size: 18px;
    line-height: 1.5;
}
h1 {
    font-size: 32px;
}
h2 {
    font-size: 25px;
}

The browser tries the first font, then the next one. serif is a general fallback. line-height: 1.5 leaves space between lines.

Dark blue text on a pale background.

Normal body text stays at 18 pixels.

A little transparent colour

This is the rule for the pale note boxes:

.note {
    background-color: rgba(255, 221, 102, 0.25);
}

The first three numbers are red, green and blue. The last number is opacity: 0 is transparent and 1 is solid. Here the yellow is only partly visible.

Keep a small set of choices

Use the same heading sizes, link colour and box spacing on every page. That is the design system: a few choices used again instead of a new look on each page.

Try it

Change a practice heading to navy and keep the paragraph black. Add a fallback font.

Check: The heading changes, the paragraph stays readable, and both still appear if the first font is unavailable.

If it goes wrong

Light yellow text on a white background is hard to read. A colour that looks nice is not always readable. The accessibility lesson explains contrast ratios.

Next, connect pages and add an image.

Check your understanding

What does the final number in rgba(255, 221, 102, 0.25) mean?

Show the answer

It is alpha, or opacity. 0.25 is 25% opaque. The background underneath still affects the visible colour.
