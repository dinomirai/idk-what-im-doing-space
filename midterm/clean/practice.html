Lesson 10: Put it together

Goal: Put the basic pieces together in a small two-page practice site.

You have seen the separate parts. Now make a small page about something you like: a pet, a game, a hobby or a recipe. Keep the first version small.

1. Make a folder

my-practice-site/
    index.html
    about.html
    style.css
    images/
        little-house.png

Copy little-house.png from this project's images folder into your practice images folder, or use your own picture and update its filename and alt text.

2. Make the home page

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>My hobby page</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <header>
        <h1>My hobby page</h1>
    </header>
    <nav>
        <a href="index.html">Home</a> |
        <a href="about.html">About</a>
    </nav>
    <main>
        <h2>Things I like</h2>
        <p>This is my practice page.</p>
        <ul>
            <li>Drawing little houses</li>
            <li>Learning one tag at a time</li>
        </ul>
        <img src="images/little-house.png"
             alt="A small blue house with a yellow door">
    </main>
    <footer>
        <p>Made for practice.</p>
    </footer>
</body>
</html>

3. Add a few CSS rules

body {
    max-width: 800px;
    margin: 20px auto;
    padding: 16px;
    background-color: #fffde9;
    color: #000000;
    font-family: Georgia, serif;
    font-size: 18px;
    line-height: 1.5;
}
a {
    color: #000080;
}
a:focus {
    outline: 3px solid navy;
}

Expected result

A pale page with a large heading, two links, a short list and the house picture. It should be centred on a wide window and fit a narrower one.

4. Make the second page

Copy the whole HTML example into about.html. Change the title to “About my hobby,” change the heading and write a short paragraph. Keep the same navigation and stylesheet link on both pages.

Try it

Open index.html and follow About, then Home. Add a details/summary question if you want another bit of practice.

Check: Both links work, both pages use the same CSS, the image appears and the question opens without a script.

Before you call it done

  • Save all files and refresh the browser.
  • Test every menu link and any jump links.
  • Read your examples and compare them with the visible results.
  • Check headings, alt text, keyboard focus and zoom.
  • Credit any reference, image or video you used.
  • Zip the whole folder, not just index.html. Extract it somewhere else and test it again.

If it goes wrong

Do not use a path like C:\Users\YourName\Desktop\photo.png in your HTML. It only points to your computer. Keep the file inside the project and use a relative path such as images/photo.png.
