Lesson 1 of 10 · about 6 minutes

Lesson 1: Basic HTML

On this page: A very small page · What you should see · Try it · Check your understanding

Goal: Make a page with one main heading, a paragraph and a list.

HTML describes the content of a page. A tag gives the content a job. For example, <p> starts a paragraph and </p> ends it.

A very small page

Type this into a new file named index.html. Save it, then open it in a browser.

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>My first page</title>
</head>
<body>
    <h1>My little page</h1>
    <p>I am learning HTML.</p>
    <ul>
        <li>Save my file</li>
        <li>Open it in a browser</li>
    </ul>
</body>
</html>

What you should see

My little page

I am learning HTML.

  • Save my file
  • Open it in a browser

The example above shows the page content; your browser supplies its default heading size. This tutorial styles its example heading to fit the lesson.

What do those parts do?

  • <!DOCTYPE html> tells the browser to use modern HTML.
  • lang="en" identifies English, charset="UTF-8" supports text characters, and the viewport line lets the page use the device width.
  • <head> holds page information. The title appears in the browser tab.
  • <body> holds the visible page.
  • <h1> is the main heading. Use <h2> for sections under it.
  • <ul> is a bulleted list. Each item goes in <li>.

Give parts of the page a job

<header> holds introductory content, <nav> holds navigation, <main> holds the main content, and <footer> holds closing information. These names explain the structure.

Common mistake

Write the closing tag with a slash so the end of your paragraph is clear. HTML can sometimes infer a paragraph ending, but explicit closing tags make beginner code easier to follow.

Unclear: <p>Hello.<p>
Clear: <p>Hello.</p>

Try it

Change the heading to your name and add a third list item. Save and refresh. The new heading and item should appear.

Check: Compare your saved page with the example above, then test the change described in the practice activity.

Check your understanding

Where do the visible heading and paragraph belong: head or body?

Show the answer

They belong inside <body>. The <head> holds information such as the browser-tab title.
